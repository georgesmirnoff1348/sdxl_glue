# Eng
## What does it do / plan to do?
I built this lightweight blending utility to merge different layers generated by local SDXL instances and eliminate the "pasted-together" collage effect.

The core idea is to leverage a diffusion model to seamlessly blend two layers together — smoothing not just global lighting (similar to IC-Light), but harmonizing all visual details and textures.

Currently, the tool does not meet my expectations: it tends to degrade the collage quality rather than improve it, mainly due to sub-optimal inpainting hyperparameters.

With a proper auto-tuning mechanism for generation hyperparameters, this tool could become significantly more useful. If you find this project interesting or useful, feel free to submit a Pull Request or open an Issue — I will be glad to continue working on it and polish it up!

# Rus
## Что оно делает/должно делать?
Создавал этот небольшой склеиватель для разных слоев, сгенерированных SDXL на локальном компе с целью избежать эффекта коллажа. 
Смысл в том, чтобы с помощью диффузионной нейронки притереть два слоя друг к другу -- глобально сгладить не только освещение (как в ICLight), но в целом все детали.
На текущий момент меня не удовлетворяет, как работает этот инструмент -- он скорее портит коллаж, чем улучшает его, из-за неидеального подбора гиперпараметров инпейнта.
Если доделать небольшой автоподбор гиперпараметров генерации, возможно, этот инструмент будет куда полезнее. Если Вам было бы интересен этот инструмент -- пишите пулл реквест, и я обязательно его доделаю.
